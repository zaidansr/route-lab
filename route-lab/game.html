Installation and Connect / Disconnect request Windows administrator approval. A connection is accepted only after an authenticated relay handshake; failed connection setup rolls back its tunnel.

This page controls real destination-based routes. Every application sending to a listed IP uses that route. It does not identify game traffic automatically, and real mode currently uses one relay. No owned relay is configured by default.

1. Prepare an owned relay

Enter an existing server you control and game-server IPs you have verified. This generates private client and server files locally. It does not create or purchase a server.

Copy the generated server files to your relay and follow relay-server/README.md. Private keys stay in the local protected .private folder and are never displayed here.

2. Connect a prepared profile

Deploy the matching server configuration before connecting. Disconnect a tunnel before changing profiles or closing this dashboard.
